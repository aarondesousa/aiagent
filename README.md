# AI Agent

A stateful AI agent built to navigate a codebase, identify bugs, and execute fixes. 

This project was developed as part of a guided course on Boot.dev to learn about AI agents, LLM tool calling, and multi-turn feedback loops.

> ⚠️ **Warning:** This repository is built strictly for educational purposes. It executes untrusted code generated by an LLM directly on the host machine's runtime.

## ⚙️ How It Works

The agent uses a multi-turn feedback loop powered by the Gemini API (`gemini-2.5-flash`). It has access to a set of local tools allowing it to:
* List files and directories
* Read file contents
* Write or overwrite code
* Execute Python scripts via subprocesses

For safety, file utilities are strictly restricted to the target directory configured in `config.py` (defaults to `./calculator`) using path validation, though script execution occurs natively on the host runtime.

## 🚀 How to Run

> 📦 **Prerequisite:** Python **3.10 or higher** and [uv](https://github.com/astral-sh/uv) must be installed on your system.

1. Clone the repository:
    ```bash
    git clone https://github.com/aarondesousa/aiagent.git
    cd aiagent
    ```

2. Create your local environment file:
    ```bash
    touch .env
    ```

3. Open `.env` and add your Gemini API key:
    ```env
    GEMINI_API_KEY=your_actual_api_key_here
    ```

4. Run the agent loop with a prompt:
    ```bash
    # uv will automatically set up the virtual environment and install dependencies
    uv run main.py "Scan the repository and run the tests."
    ```
